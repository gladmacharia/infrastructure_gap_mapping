# Backend

FastAPI backend for the Kenya Infrastructure Gap Mapping System.

## Technologies
- Python
- FastAPI
- asyncpg
- PostGIS
- Groq LLM

## Features
- REST API
- Spatial queries
- Infrastructure analysis
- Natural-language AI interpretation
- GeoJSON generation
- Dashboard statistics
- Location search

## AI Data Flow
Question → LLM → Structured Intent → PostGIS Analysis → GeoJSON → Frontend
